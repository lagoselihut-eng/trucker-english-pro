TRUCKER ENGLISH PRO — versión inicial 0.1

CONTENIDO
- Analizador inicial de frases y detección de formas comunes de TO BE y verbos.
- Simulador básico de preguntas DOT.
- Catálogo inicial de señalamientos para camiones.
- Vocabulario de partes y mecánica.
- Síntesis de voz en inglés estadounidense usando voces disponibles en Android/navegador.
- Dictado/reconocimiento de voz si el navegador lo admite.
- Progreso local en el dispositivo.

INSTALACIÓN EN ANDROID
1. Sube esta carpeta a un hosting HTTPS (por ejemplo, un sitio estático).
2. Abre la dirección HTTPS en Chrome para Android.
3. Menú ⋮ > Instalar aplicación o Añadir a pantalla de inicio.
4. Para uso offline, abre la app una vez con conexión para que el service worker guarde los archivos básicos.

LIMITACIONES IMPORTANTES
- Esta es una primera versión educativa; el analizador gramatical es heurístico, no un motor de IA completo.
- Las voces masculina/femenina dependen de las voces instaladas en el dispositivo; Android puede no exponer etiquetas de género.
- El reconocimiento de voz depende del navegador, permisos y conexión.
- El contenido DOT y de señales es introductorio. Confirma requisitos vigentes con FMCSA, MUTCD, TxDOT y las autoridades aplicables. No uses una respuesta modelo para declarar algo que no sea cierto.
